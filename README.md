#SISTEMA DE GERENCIAMENTO DE LIVROS.

SOBRE O PROJETO:

Este projeto consiste no desenvolvimento de um sistema para gerenciamento de livros de uma biblioteca. A ideia é permitir que o usuário organize o acervo de forma simples, podendo cadastrar, consultar, atualizar e excluir livros.

O sistema está sendo desenvolvido como atividade acadêmica do curso de Engenharia de Software, com o objetivo de colocar em prática os conhecimentos de programação e trabalho em equipe.

FUNCIONALIDADES:

- Cadastro de livros.
- Listagem dos livros cadastrados.
- Busca de livros pelo código.
- Edição das informações dos livros.
- Exclusão de livros do acervo.

TECNOLOGIAS UTILIZADAS:

- Python
- Git e GitHub
- Visual Studio Code

COMO EXECUTAR?

1. Instale o Python no computador.
2. Clone ou baixe o repositório.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o arquivo principal `main.py`.
